ARVIN

A real-time voice AI that can hear, see, speak and control your computer. Built on the Gemini Live API. No subscription: bring your own free Gemini key.

Windows macOS · Apple Silicon macOS · Intel Linux

Phone or tablet? ARVIN runs on your computer, and your phone becomes its remote. See below. · View on GitHub

What it does

Real-time voice

Low-latency conversation in any language through Gemini 3.1 Flash Live.

Controls your computer

Launches apps, manages files, drives the browser, and adjusts volume, brightness and WiFi by voice.

Sees your screen

Screen capture and webcam vision go straight into the conversation.

Holographic avatar

An animated head in the HUD with real lip-sync, blinking and gaze.

Remembers you

Persistent memory you can inspect and delete from the memory panel.

Undo & real confirmation

Take back file moves and setting changes. Shutdown and restart wait for a button you press.

Video on the HUD

Plays YouTube, a local file or any URL where the avatar sits, muted until you ask for sound.

Wake word

Local, offline wake-word detection. It never streams audio while asleep.

Plugins

Drop a single .py file into the plugins folder and ARVIN learns a new skill.

Install

Windows 10 / 11

Unzip, open the ARVIN folder and run ARVIN.exe. If SmartScreen warns you, click More info → Run anyway.

macOS

Unzip and move ARVIN.app to Applications. The first time, right-click → Open. Allow Microphone and, if you like, Screen Recording and Accessibility.

Linux

tar -xzf ARVIN-linux-x64.tar.gz, then run ARVIN/ARVIN. Needs PortAudio: sudo apt install libportaudio2.

Then get a free API key from Google AI Studio and paste it into the setup screen.

Your key, settings and memory stay on your computer, in Application Support (macOS), %APPDATA% (Windows) or ~/.local/share (Linux).

On your phone or tablet

ARVIN controls a computer, so it runs on one. Your iPhone, Android phone or tablet becomes its remote: in ARVIN, press Remote Control and scan the QR code. You can talk to ARVIN and send it files from your phone over your home WiFi. Nothing to install.

Run from source (Windows, Linux, macOS)

git clone https://github.com/Nishchay869/ARVIN-Personal-Assistant.git
cd ARVIN-Personal-Assistant
python setup.py
python main.py

Requires Python 3.11–3.13 and a microphone.
